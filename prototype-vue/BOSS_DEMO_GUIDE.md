# 老板演示说明

## 入口

- 本地启动脚本：`start-demo.bat`
- 浏览器入口：`http://localhost:5173/demo`

## 推荐演示顺序

1. 进入“广告主”角色，创建广告
2. 在“素材管理”中上传素材
3. 切到“审核员”角色，审核通过素材
4. 切到“业务运营”角色，创建投放计划并上线
5. 切到“运维工程师”角色，查看设备状态和大屏播放模拟
6. 切到“财务账号”角色，查看账单结算
7. 切到“审计账号”角色，查看全流程日志

## 演示过程中常用操作

- 右上角“演示入口”：随时返回角色选择页
- 右上角“恢复演示数据”：把所有状态恢复到初始演示状态
- 右上角“切换角色”：快速切到其他角色

## 推荐给老板的讲解重点

- 这是“网页端演示版”，目的是先跑通主线流程
- 当前使用的是假数据和本地状态流转，不依赖真实后端
- 重点演示“广告创建 -> 素材审核 -> 计划上线 -> 设备播放 -> 账单结算 -> 日志审计”
- 如果进入了错误状态，可以直接点击“恢复演示数据”
